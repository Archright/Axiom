## Quick Commands Reference

| Action | Command |
|--------|---------|
| List all stashes | `git stash list` |
| Show stash summary | `git stash show stash@{N}` |
| Show stash diff | `git stash show -p stash@{N}` |
| Show stash stat | `git stash show --stat stash@{N}` |
| Drop specific stash | `git stash drop stash@{N}` |
| Pop without commit | `git stash pop stash@{N}` (⚠️ may cause conflicts) |
| Apply without removing | `git stash apply stash@{N}` |

**⚠️ WARNING**: Do NOT use `git stash clear` — it removes all 18 stashes at once. Always use targeted `git stash drop stash@{N}` operations.

**⚠️ NOTE**: Index numbers shift after each drop. Always run `git stash list` before targeting a specific stash. Drop from highest index first to avoid renumbering issues: {17}, {16}, {15}, ..., {0}.
