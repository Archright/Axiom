# ADR-0009: Decision Binding Framework

## Status
Accepted

## Context
Stateless agent sessions cannot discover "why" decisions were made. When an agent encounters a symbol like `type ProofReceipt = object { ... }`, it can read *what* the type looks like but not *why* it was designed that way. The current system requires agents to "pull" context from scattered sources — commit messages, PR descriptions, ADR documents — a process that is lossy, time-consuming, and unreliable. As the codebase grows, this discovery cost compounds: each new agent session spends significant tokens locating decision rationale before it can safely modify code.

## Decision
Implement a 4-pillar push-based decision narrative system:

1. **AST Annotation** (`{.axiomDecision.}` pragma): Every public type/proc carries compile-time metadata encoding ID, rationale, ADR reference, and version. Zero runtime cost.
2. **Decision Knowledge Graph** (`decisions_graph.json`): Machine-readable index generated by linter, tracking coverage and dependencies across all annotated symbols.
3. **Context IR 2.0**: ~~Lazy decision injection into `.axiom/context.ir`~~ — REMOVED 2026-08-07 (dead channel; decision narrative discovered via source + AGENTS.md).
4. **CI/CD Deterministic Linter**: Native binary (`bin/decision_binding_lint`) enforces annotation requirement at build time. Operates in warning mode during grandfathering, transitions to error mode once all public symbols are annotated.

Grandfathering via `config/decision_binding.waiver.toml` allows existing symbols to carry `LEGACY-0000` markers while migration proceeds incrementally across 5 phases (8 weeks).

## Alternatives Considered
- **Pull-based ADR directory scanning**: Agents scan `docs/adr/` at boot. Rejected: O(n) cost per session, easy to miss relevant ADRs, high staleness risk.
- **Runtime metadata injection**: Embed decision data in compiled binaries. Rejected: breaks hermetic builds, adds runtime overhead, incompatible with static linking.
- **Comment-only convention**: Standard comments instead of pragmas. Rejected: no compile-time enforcement, easily overlooked by agents, not machine-parseable without AST analysis.

## Consequences
- All public symbols must carry `{.axiomDecision.}` pragma (enforced by linter)
- ~~Context IR 2.0 enables lazy decision injection, reducing agent boot token cost~~ — REMOVED 2026-08-07 (dead channel)
- Grandfathering prevents immediate CI breakage; gradual migration path over 8 weeks
- Native binary linter ensures deterministic output and zero VM overhead
- Waiver system (`config/decision_binding.waiver.toml`) provides visibility into unannotated symbols
- Decision Knowledge Graph (`decisions_graph.json`) serves as coverage dashboard for maintainers
- **D-30 Progressive Escalation**: Waiver expiration uses three-state model (PASS → WARN → FAIL) instead of hard fail. Expired waivers enter a 30-day warning period before blocking CI builds. Configurable via `--escalation-threshold` parameter (default 30 days, 0 = immediate fail).
