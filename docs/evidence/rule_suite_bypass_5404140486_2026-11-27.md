## §5. Theater found and repaired (DEBT#573)

Two defects in the same merge job, registered as one debt (Theater, `theater_audit`):

1. **Dead gate.** The cross-shard duplicate-path check read the **merged** report, whose jq program ends
   `… | group_by(.path) | map(.[0])`. Grouping by path collapses every repeated path to exactly one
   entry, so the following `sort | uniq -d | wc -l` test was empty for **every possible input**. The
   check advertised a cross-shard duplicate guarantee it could not enforce (AGENTS.md §0.9).
   **Repair**: the guard now runs on the **raw per-shard reports**, before the merge jq
   (`publication-integrity.yml:351`), so a path emitted by two shards is observable; the post-merge
   location was deleted rather than left as a second, still-dead copy.
2. **Swallowed diagnostic.** The shard count came from `… | grep -c .`, which exits 1 on zero matches;
   under `set -euo pipefail` inside a command substitution the assignment aborted the step, so an empty
   shard directory produced a bare `exit 1` with **no message**. **Repair**: the count is taken with a
   construct that always exits 0 (`awk 'NF{c++} END{print c+0}'`), leaving the single `-eq 5` assertion
   as the one deciding and reporting point. `|| true` was deliberately **not** used — that construct is
   ruled CI Theater by `bin/anti_theater_gate` on `.github/workflows/**` and would also defeat `set -e`.

Both repairs are pinned by negative tests, not by assertion: restoring the duplicate guard to its
post-merge position reddens **only** the duplicate case; restoring `grep -c` reddens **only** the
zero-shard case; narrowing the matrix to 4 legs reddens **only** the site-agreement and drift cases. Each
repair is therefore pinned by the case that names it. `make check-workflow-shell-syntax` (281 run blocks,
0 failures), `make check-nim-theater`, `bin/anti_theater_gate` on the staged diff, `bin/debt_engine
--validate` (1891/1891) and `bin/debt_integrity_gate` all passed on the landing tree.
