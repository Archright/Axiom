# CI Pipeline Health Evidence

## Purpose
This directory contains evidence files from remote CI pipeline monitoring.
Generated by `bin/ci-health` (tools/ci/ci_health_checker.nim).

## Files
- `latest.json` — Most recent CI status check (read by ci-pipeline-health-gate)
- `{sha}.json` — Per-commit evidence files
- `error.json` — Written when API is unreachable

## Architecture
- **Evidence Layer**: `bin/ci-health` polls GitHub API, writes here
- **Gate Layer**: `ci-pipeline-health-gate` reads `latest.json` ONLY (no network)
- **Self-Healing**: `fix(ci):` prefix or `Axiom-CI-Fix: true` trailer bypasses gate
