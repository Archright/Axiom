## A2.1 갭 1 — CAS-REUSED 런의 목적별 분류와 표본 정의

### A2.1.1 실측 동기

런 `38092265644`(2026-10-10T22:39:54Z, merge_group): Judgment CAS 4종 전부 `basis=REUSED` → `[admission-tests] SKIP` ×4, GO-critical 스텝 0 s, 런 wall 563 s (`admission-check.yml:1046-1056` — 저장된 판정 기록이 plan 시점 재검증되면 커널을 실행하지 않는 **설계된 재사용 경로**). 0 s는 검증 작업 시간이 아니므로 소요 통계에 넣을 수 없지만, 이 런의 존재·wall-clock·운영 결과는 실재한다. 관측 창의 지불 비율은 φ_pay = 9/10 (decomposition §6). 유형별 처리 규칙이 없으면 (a) 0 s가 Δ̂ 표본에 유입되거나 (b) 런이 조용히 버려져 유효 n이 실제 수집량보다 짧아지는 두 가지 오류 경로가 열린다.

### A2.1.2 유형 분류 (기계적, GO-critical 스텝 로그만 사용)

| 분석 목적 | REUSED 런 처리 |

### A2.1.4 표본 정의 개정

- **n_C = 30 = "OBSERVABLE duration" 런** (유형 `EXECUTED`, 원계약 §5.4 나머지 기준 충족) — **전체 런 수가 아니다**. `FULL_REUSE`/`PARTIAL_REUSE`/감증 실패 런은 ledger 기록되지만 n_C 진행 없음 → 수집 계속(§5.4 기존 메커니즘). 이 규정이 없으면 REUSED 런 다수로 유효 표본이 계획보다 짧은 채 분석이 진행될 수 있다.
- **n_B = 12 동일 정의** — HIT 감증(A1) + `EXECUTED` + 개입-이후 코드. A1의 소요-사전관측 제외와 **누적 적용**이다 (A1을 변경하지 않는다).
- REUSED 식별에 필요한 SKIP/RUN 라인 판독은 **설계 변수 확인**(원계약 §5.6(c)가 허용하는 포함기준 확인)이며, 소요값 추출이 아니므로 중간 추출 금지와 정합한다.

## A2.2 갭 2 — δ 게이트 ACTION 규칙 완결 (숫값 사전고정)

출발점: decomposition §9.2 — δ ≤ 60 s 채택, (60, 126.4] (a) 보류·(b) 재평가, > 126.4 s 전면 보류, 카덴스 < 2.2 merge_group 런/일 붕괴. 아래가 빠진 ACTION을 채운다.

### A2.2.1 δ_obs 정의·측정

`δ_obs = 병렬 GO-critical 스텝 벽시계 − max(단일 테스트 소요)` (§9.2.1 정의 유지). 1차 값 = 로그 라인 7자리 타임스탬프(원계약 §7.2 불변); per-test in-step `date +%s%N` 기록값을 상호검증 어댑터로 병행 기록; API `steps[]`는 fallback(초 해상도 ±1 s, §7.2).

### A2.2.2 경계 밴드 x = ±5 s

**밴드 = (60 − 5, 60 + 5] = (55, 65] s.** 근거: (i) 측정 오차 합성 — 로그 라인 하위초 + 스텝 경계 정렬 ±1–2 s + API fallback ±1 s → 체계 오차 ≤ ~2 s, x=5 s는 그 2.5배; (ii) (a)vs(b) 지배 교차점 63.0 s(decomposition §9.2.1)가 밴드 **내부** — 밴드는 정확히 경제적 모호 구간을 덮는다; (iii) 게이트 60 s의 8.3%로 실효과를 삼키지 않는다. 착정 규칙: **δ ≤ 55 결정적 채택, δ > 65 결정적 미채택, (55, 65] 밴드 → A2.2.3**.

### A2.2.3 밴드 반복 규칙 (m=2, warm 정의)

밴드 관측은 **단독으로 착정하지 못한다**. 요건: 동일 후보 코드(Git merge 커밋 OID 일치) 위의 merge_group 런 2건 추 관측, 각각 **warm** — 정의: `[test-supply] restored build/nimcache/test entries=N` 로그 존재 ∧ **N > 0** ∧ 값 기록. 두 관측이 밴드 밖 같은 쪽 → 그 쪽 착정; 밴드 내·엇갈림 → 미결 → 72 h 내 미해소 시 A2.2.4의 미채택 귀결. 반복 관측은 ledger에 기록한다.

### A2.2.4 중간밴드 ACTION — 사전-착지 케이스 (δ_verif > 65 또는 밴드 해소 미채택)

병렬화 코드는 **main에 착지하지 않는다**(기존 직렬 경로 무변 — decomposition §9.3). (b) 별도-job 재평가는 **경계가 있다**: 첫 미채택 관측부터 **최대 K_mb = 5 검증 런 또는 T_mb = 72 시간**, 먼저 도달하는 쪽에서 창 종료. 종료 시 착정은 둘뿐: (i) (b) 채택 — 실측 `prep_job(b) ≤ 120 s`(H 양성 상한, §9.2.2 전제) ∧ 4배 러너 과금 수용이 기록된 경우에만; (ii) **보류 아카이브**(기록과 재개 조건 명시). 창 닫힘 후 무기한 재평가는 금지.

### A2.2.5 중간밴드 ACTION — 사후-착지 노출 경계 (지속 창 내 δ_obs > 65)

채택 후 벗어남은 **이미 지출된 저속 런을 회복할 수 없으므로**(revert는 미래 비용만 차단) 노출 창을 명시 봉인한다: 첫 δ_obs > 65 관측부터 **T_exp = 24 시간 또는 K_exp = 10 지불 런**, 먼저 도달하는 쪽에서 **강제 착정**: revert 또는 근거 기록 재평가 1회(연장 창 동일 경계, **1회 한정**). 같은 지속 창(A2.5 C2) 내 두 번째 > 65 관측 → **revert 강제** (연장 소멸).

- 최소 표본: 각 코호트 **n ≥ 8 지불 런**, 코호트×층 **≥ 2 런**(A2.3.3-iv).

### A2.3.2 자격·레짐 가중

- 층화: a-restore 마커, 임계 40,000 ms(원계약 §5.2 불변).
- **1차 통계**: 계획 가중 **w_L = 2/3, w_H = 1/3**(decomposition §4의 관측 L-우세 6/9 — 착지 전 기록, peeking 아님)을 **양 코호트에 공통 적용**한 층 평균 wall-clock의 가중 차 `D̂ = W_base − W_par`. 층별 평균·중위수 병기. 한 층이 한 코호트에서 공백 → 관측 층으로 재가중 + **주장 관측 층 제한**(§5.2 공층 규칙 준용).
- 의존성: 세대 귀속(§5.3) 동일 적용 — 세대 공유 런은 비독립.

### A2.3.3 판정 규칙 (사전고정)

**성공 = 전부 충족**:
1. **물질성**: `D̂ ≥ 60 s` — 근거: δ 게이트 통과(δ≤60) 하한에서 기대 절감 = 가중 `S_repeat = 201.5 − δ ≥ 141.5 s`(§7)이나 §7.1의 스텝↔wall 비변환 원칙상 1:1 주장은 금지 → 독립 보수 하한 60 s.
2. **통계**: `D̂`의 편측 95% 하한 > 0 — 추론은 **세대-평균 2표본 t, df = min(G_base, G_par) − 1**(A2.4 교정 절차 — §5.3 세대 의존성과 정합).
3. **부호 일치**: 관측된 각 층에서 `D_s > 0`.
4. **최소 표본**: A2.3.1 + `min(G) ≥ 3`.

**미확정**: 1–4 불충족이 **표본 부족 기인**(n·G 미달, 층 공백) → "미확정" (성공 아님). **FAIL**: 충분한 표본에서 하한 ≤ 0 또는 D̂ < 60 s.

### A2.3.4 §5.6(c)·§7.1 정합 — 목적 분리 방화벽

본 기준은 **런 레코드 필드**(§7.1)만 소비하며 GO-critical 소요 추출이 아니다. 선행계약(decomposition 문서)이 이미 확증 분석과 별도 목적으로 스텝 시간을 소비한 선례가 있다. 방화벽: C2/C3 목적의 추출·기록은 ledger에 남기고, **E3 Δ̂의 수집·멤버십·n·분석 시점은 결과값과 무관하게 기계적**(§5.4+A1+A2.1)이므로 이 관측이 확증 설계 결정을 바꿀 수 없다. Δ̂ 단일 분석(§5.6)은 그대로 봉인. `T_land` 이후 런이 Δ̂ 확증 집합에 포함되면 실행 모드(직렬/병렬)를 런별 기록하고 per-모드 민감도를 보고한다(모드 변경은 n·멤버십 규칙을 바꾸지 않는다).

## A2.4 갭 4 — 소규모 세대 블록 부트스트랩 유효성 판정과 교정 추론

### A2.4.1 구조적 논거 (G=2–4에서 백분위 부트스트랩의 실패는 구조적)

- G=2: 세대 재표집 다중집합 = C(3,2) = **3종** → Δ̂* 부트스트랩 분포는 9개 값(양 arm 3×3) — 5% 꼬리 보정 불가.
- Rademacher WCB 최소 도달 편측 p = **1/2^G** — G=4에서 0.0625 > 0.05 → 5% 거절 **원리적 불가** (w=all+가 t*=t_obs를 유일하게 보장).

### A2.4.2 문헌 (선별 — 전부 A2.6에 URL)

- Cameron–Gelbach–Miller (2008, RESTAT): wild cluster bootstrap 원론 — 소규모 G에서 클러스터 추론 개선.
- Roodman–Nielsen–Webb (2019, Stata J): WCB 구현·G≤12 Webb 6점 가중치 권장.
- MacKinnon–Nielsen–Webb (2023, J. Econometrics 가이드): 소수 처리 클러스터·high leverage 과대-rejection 경고.
- Ibragimov–Müller (2010, JBES) · Bester–Conley–Hansen (2011, J. Econometrics): 소수 독립 블록의 집계 t 추론 — **t(G−1) 계열 임계값**.
- Method Atlas 요약표: G<10 CR1 불신뢰, G<20 WCB/RI 권장, **G<5 "all bets off"**.
- Burtch (2026-09) 몬테카를로: G=2 WCB 커버리지 70.9%(60%는 구간 미반환), G=4 87.1%, G=6 93.7% — **G≤4에서 WCB도 무효**.
- fwildclusterboot 문서(Context7): WCB 변형·`webb` 소클러스터 가중치 현행 구현 확인.

### A2.4.4 판정

- **계약 §5.3 백분위 세대 블록 부트스트랩은 G_B=2–4(및 시험한 전 셀)에서 편측 95%로 무효** — 거짓-확증 8.5–15.8%(명목 5%의 1.7–3.2배), 진효과 커버리지 84.2–92.3%(< 95%). → **그대로는 확증 차량으로 사용 불가.**
- WCB(Rademacher·Webb): 이 설계에서 거절률 0.0% — 거짓-확증 없으나 **검정력 0**(죽은 게이트) → 차량 불가.
- Welch-df 클러스터 t: 일부 셀 3.9–7.1%로 반보수적 → 기각.
- 런 수준 독립 t(§5.3 금지 대조군): 거짓-확증 최대 24.6% — 금지의 정당성 재확인.
- **t(min(G)−1) 세대-평균 2표본 t: 전 셀에서 보수적** — 거짓-확증 0.1–3.9% ≤ 5%, 커버리지 96.1–99.9% ≥ 95%.

### A2.4.5 교정 절차 (사전고정 — 원계약 §5.3·§5.7의 추론 차량 교체, 단방향 축소)

- **G_min = min(arm별, 층별 독립 세대 수) ≥ 3** → §5.7 Tier 1/2의 CI는 **세대-평균 2표본 t, 편측 95%, df = G_min − 1** (t_0.95,2 = 2.920, t_0.95,3 = 2.353, t_0.95,5 = 2.015). 백분위 블록 부트스트랩(B=10,000)은 **기술적 재표집 검사로 강등** — 주장 근거에서 배제. 표본 단위(런)·G 집계 규칙·퇴화 규칙(<2 세대 = 단일 세대 관측)은 §5.3 그대로. **백분위 부트스트랩으로 되돌리는 완화는 금지**(t 임계값 ≥ 정규 분위수 — 항상 더 넓은 하한).
- **G_min = 2 → 종단 상태 "Tier 1 추정 산출 / 독립 블록 부족으로 확증 불가"**: 추정치·하한을 보고하되 Tier 1·2 확증 선언 **금지** — t(1) 하한이 0을 넘어도 마찬가지(시뮬상 t(1)은 수치적으로 보수적 0.1–0.6%이지만, 2 블록은 세대 수준 교란 — 시드 창 공유 환경 — 를 배제할 수 없고 실측 검정력 2.3–5.3%로 사실상 검출 불가; 2블록 확증 선언은 §0.9 극장).
- **층 적용**: G_s,min = min(G_B,s, G_C,s) — Tier-1은 **G-valid 층(G_s,min ≥ 3)에서만** 판정; G-invalid 층은 보고만. 모든 달성 층이 G_min ≤ 2 → 전체가 종단 상태. 민감도(§5.2) 변형에도 동일 df 규칙 적용.

병렬화의 "목적-증명" = 다음 세 기준의 **동시 PASS** (하나라도 FAIL → FAIL, 하나라도 미확정 → 미확정):

- **C2 — δ 게이트**: 검증 런(**후보 병렬 코드** 위 웜·지불 런 — 관측상 지불층은 merge_group; 이벤트 유형 기록) 채택 통과(결정적 δ ≤ 55 또는 A2.2.3 밴드 해소) ∧ **지속 창** = [T_land, min(20 지불 런, 14일)] 내 전 관측 δ_obs ≤ 65 (A2.2.5 ACTION 연계). 창 내 지불 관측 < 8 → C2 미확정.
