## §0. What this document records

`Makefile:40-46` declares `GATES_FAST` (10 targets) and `GATES_STATIC` (14 targets). `Makefile:611`
aggregated the 24 of them as `local-verify-static`. Measured over the only two surfaces that can gate
anything — every `make` target invoked from `.github/workflows/**` and `.githooks/**` — exactly one
member of that declared set (`check-nim-theater`) actually ran. The declaration and the executing
surface were different sets, so a red static gate could not block a merge: the nimtry fingerprint
drift repaired by PR #534 sat undetected on `main` for that reason.

PR #535 made the declared set the executed set: a `local-verify-static-ci` Makefile target invoked by
one step of `.github/workflows/axiom-operational-slice.yml`. That workflow file is a member of
`config/policy/trust_surface_manifest.json`, so App `5795152` (`axiom-admission-verifier`) refused the
PR by design and the normal merge queue was structurally unavailable for the landing (DEBT#558). The
MUST-T2a delegation was registered as a PR comment **before** the merge command; a temporary bypass was
granted on the two rulesets carrying required checks; the landing was performed through the REST merge
endpoint pinned to the PR head; and the rulesets were restored byte-identically.
