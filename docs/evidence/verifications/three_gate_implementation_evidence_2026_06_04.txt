## What Was Fixed (Phase 1 — Fundamental)
========================================================================

1. stagnation variable moved outside while loop
   - Before: reset every iteration → consecutiveFailures never accumulates
   - After: persists across iterations → 3 consecutive failures triggers escalation

2. recordFailure() pipeline restored
   - Before: 0 callers in entire codebase
   - After: called on every Lean kernel rejection path

3. Geometric Mean NaN/zero guard
   - Before: pow(0.0, 1/3) could produce edge cases
   - After: product <= 0.0 → explicit 0.0 sentinel
   - Empty signals → -1.0 sentinel (distinct from "no issues" = 1.0)
