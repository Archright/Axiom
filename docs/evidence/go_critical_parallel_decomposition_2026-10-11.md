## 1. 결론 요약 (설계 결정)

최장 단일 테스트 소요; 병렬화 자체의 경합·캐시 마찰 비용 — 본 워크스트림에서 구현·측정

  이것은 **이상 총량 상한**이다(§5). 순 상한: L `239.0−δ`, H `126.4−δ`.
  작업 지시서의 238 s(냉)/129 s(웜)와 일치(원자료 재계산).
- **S_K(30일 지평, K=1,368)**: E[S_K] ≈ **271,000 s ≈ 75 러너시간** (δ=0),
  δ=60에서도 ≈ **52 러너시간**. 손익분기 δ ≈ 198 s — 레짐 양성 조건(δ<126.4) 밖.
- **P(S_K < 0)**: δ ≤ 60 s 조건에서 **관측된 모든 일 수요(18–89런/일)에 대해 0**.
  무조건부 P(S_K<0) = P(δ > ~118–126 s) — 미측정, 1회 실험으로 해소된다. 채택 변경은
  되돌릴 수 있으므로(revert) 하방이 봉인된다(§9.4).
- **기각**: 접근 (b) 별도 job 4개 — H 레짐 순절감 63.4 s로 (a)에 지배되고, job 준비
  상단(131 s)에서는 **음수**(−4.6 s)가 될 수 있다(§5.3). 접근 (c) 외부 래퍼 격리 —

- **결정을 바꾸는 측정값(정확한 임계)**: δ > **60 s** → (a) 보류, (b) 재평가;
  δ > **126.4 s** → 병렬화 전면 보류(H 레짐이 손해). 지속 < **2.2 merge_group 런/일**
  (30일 K < 23) → S_K < 0.

## 5. S_repeat — 접근별 순 절감 (공식 고정, 상한 표기 의무 준수)

고정 공식: `S_repeat = T_serial − T_parallel,total` (prep·경합 전부 포함 — 재공제
금지). **239.0 s / 126.4 s는 이상 총량 상한(4테스트 완전 병렬, 최장=s1a)이지 순
절감이 아니다** — 모든 숫값에 상한임을 표기한다.

### 5.1 접근 (a) — 기존 스텝 내 `&`/`wait` + 테스트별 nimcache 격리

- 추가 환경 준비 0(같은 job), 직렬 전후 봉투 불변 →
  `T_parallel,total = 0.02(전주) + s1a + δ`.
- **S_repeat,L(a) = 239.0 − δ / S_repeat,H(a) = 126.4 − δ** (상한; δ 미측정 §1).
- 근거 구조: 4종을 병렬로 돌려도 최장 s1a가 지배 — 상한이 s1a인 이유.

### 5.2 (참조) 이상 상한의 원자료 재계산

- L: 546.8 − 307.8(s1a) = **239.0 s** (지시서 238 s와 일치 — 냉 코호트 재계산).
- H: 283.6 − 157.2 = **126.4 s** (지시서 129 s — 웜 표본 [29,166,81,19] 합 295 →
  166 기준 128.5; 확증 2표본만 쓰면 278.1 − 152.7 = 125.4). 본 문서는 관측 전체
  평균 기준 126.4을 표제로 쓰고 확증값을 병기한다.

### 5.3 접근 (b) — 별도 job 4개 (fan-out/join)

- 신규 job 환경 준비를 **각 테스트 job이 반복 지불**하고 임계경로에는 최대값이
  재난다: `T_parallel,total = prep_job + s1a`. 실측 `prep_job ≈ 63 s`
  (Set up 1 + checkout B 3 + toolchain 평균 56 [45–70] + artifact 3; 작업 지시서의
  타 참측 48–131 s 상단을 민감도로 병기).
- **S_repeat,L(b) = 546.8 − (63+307.8) ≈ 176.0 s** (prep 51–78 → 161–188).
- **S_repeat,H(b) = 283.6 − (63+157.2) ≈ 63.4 s**; **prep=131 s면 −4.6 s(음수)** —
  (b)는 준비비 상한에서 스스로 부정이 된다. 추가로 러너 4배 할당(과금·대기열 위험),
  CAS 결정 파일·캐리어 병합(스텝 12–13)·fail-closed 집계의 재배선 = 설계 변경면 확대.

### 5.4 접근 (c) — 외부 래퍼 격리

결정론 증명이 요구되고(지시서 명시) 그 증명 비용이 T_rollout에 선행 — 가격 산정
불가, (a)·(b) 대비 측정된 우위 없음 → **현재 채택 근거 없음**(보류 사유 기록).

## 7. S_K 경제성

고정 공식: `S_K = K·(T_serial − T_parallel) − T_rollout`. 여기서
`T_parallel ≡ T_parallel,total`(§5 — prep·경합 이중 공제 없음).
가중 절감(달성 비례, w_L=6/9, w_H=3/9):
`Δ̄(δ) = (2/3)(239.0−δ) + (1/3)(126.4−δ) = 201.5 − δ`.

- **E[S_K(a), 30일]**: δ=0 → 1,368×201.5 − T_rollout ≈ **275,600 − T_rollout**;
  δ=60 → 1,368×141.5 − T_rollout ≈ **193,500 − T_rollout**.
- **T_rollout 성분 분류** (§8): CI-시간 성분 = 재검증 런 3–5회 ≈ **2,000–4,700 s**
  (런 wall 563–1,221 s 실측 범위). 절차 성분 = 클로저 ⑦ 진행·설계 변경·리뷰 —
  인간/에이전트 시간으로 **러너-초가 아니며** T_parallel 측정 창 밖이다.
  → E[S_K(a), 30일, δ=0] ≈ **271,000 s ≈ 75.3 러너시간**; δ=60에서도 ≈ 52.5.
- **손익분기 δ**: K=1,368에서 `δ > 201.5 − 4700/1368 ≈ 198 s` — 레짐 양성
  경계(126.4)를 넘어, S_repeat>0 영역에서는 S_K<0이 도달 불가.
- **P(S_K < 0)**: 관측 최저 월(K=540, all-H 믹스)에서도 `δ < 117.7 s`면 양수 —
  **δ ≤ 60 s 조건하에서 P(S_K<0) = 0**(관측 모든 일 수요 포함). 무조건부
  P(S_K<0) = P(δ > ~118–126 s) — δ 분포가 미측정이라 수치화 불가, **1회 검증
  런으로 해소**. 민감도: φ_pay=0.5로 반감해도 E[S_K] ≈ 41 러너시간 > 0.
- **σ의 위치**: 절감 계산에서 σ는 제외(지시서 고정) — 판정 확실성에만 영향. 실측
  레짐 sd는 2.6/9.7 s로 절감 추정의 불확도는 δ·K·φ_pay가 지배한다.

## 9. 설계 결정

### 9.1 결정: 접근 (a) 조건부 채택

`&`/`wait` 병렬 + **테스트별 nimcache 격리 디렉터리**(공유 디렉터리 동시 기록 금지 —
§8 오염 봉인) + 기존 fail-closed 전파 유지. 근거: S_repeat>0(양 레짐, δ≤60 영역),
E[S_K] 52–75 러너시간/30일, P(S_K<0|δ≤60)=0, 되돌릴 수 있는 변경.

### 9.2 채택 관문 (결정을 바꾸는 정확한 임계)

1. **δ ≤ 60 s** (1회 웜 검증 런: `병렬 스텝 벽시계 − max(단일 테스트)`).
   60 s 근거: H 레짐에서 (a)가 (b)를 지배하는 교차점 δ=63.0 s − 안전마진.
2. δ ∈ (60, 126.4] → **(a) 보류, (b) 재평가** — 단 (b)는 자체 prep 실측 ≤ ~120 s
   요건(H 양성 상한)과 4배 과금 수용이 전제.
3. δ > 126.4 s → **병렬화 전면 보류**(H 레짐 순손해; L은 δ<239까지 양성이지만
   믹스 통제 불가 — §4).
4. 카덴스 붕괴: **지속 < 2.2 merge_group 런/일(30일 K < 23)** → S_K<0, 보류.

### 9.3 failure semantics

검증 런에서 δ>60 측정 시 채택 보류 — 기존 직렬 경로 무변. 병렬 채택 후 개별 테스트
실패는 기존과 동일하게 스텝 실패 → attest 실패 → merge 블록(비영 전파 유지).
경합으로 인한 플래키는 격리 디렉터리 설계로 제거 대상이며, 채택 전 1회 검증 런 +
직렬 대조로 확인.

### 9.4 가역성

변경 단위는 워크플로+Makefile 편집 — revert로 즉시 복원. 되돌릴 수 없는 상태를
만들지 않으므로(P(S_K<0) 조항의 전제) 하방이 봉인된다.

## 10. 측정 경계 (이 기록이 주장하지 않는 것)

- **B코호트(post-#729)는 n=1(H층)뿐, L층 0건** — 레짐 경제성의 하중은 A코호트가

  기록으로).
- δ는 **미측정**이다(구현이 본 워크스트림 범위 밖). 모든 순 절감은 `−δ` 형태의
  조건문이며, P(S_K<0)=0 주장은 δ≤60 s 조건부다.
